# テスト項目

テストで確かめる中身の置き場です。本体のプロンプトも点検役（test-reviewer）も、このファイルを読みます。項目を変えるのは、えだが決めたときだけです。

## game_core（1段目）

① 地雷がちょうど40個
② 最初に開いたマスとその周り8マスに地雷がない（盤の角や辺を最初に開いた場合も含む）
③ 開いたマスの数字が、周りの地雷の数と一致する
④ 0を開くと、つながった0とその縁の数字まで開き、地雷は開かない
⑤ 旗のマスは開かない
⑥ 地雷を開いたら負け、地雷以外をすべて開いたら勝ち

## server（2段目）

⑦ ボット2人が同じ盤面を受け取り、片方の操作（開く・旗・リセット）が、もう片方にも届く
⑧ あとから入った3人目にも、その時点で見えている盤面（開いたマス・旗・勝敗）と、今いる参加者が届く
⑨ 勝敗がつくまで、地雷の位置はどのクライアントにも送らない（届く値にも混ざらない）。勝敗がついたら、負けでも勝ちでも地雷の位置が届く

## client とページ（2周目）

⑩ ページ（index.html と WASM）と WebSocket が、同じポートから届く
⑪ カーソルの位置が、ほかのプレイヤーに届く
⑫ 届いたメッセージを順に当てはめたクライアントの盤面が、サーバーの見えている盤面と一致する
⑬ クリックした画面上の位置が、正しいマスになる（盤の外は無視する）
⑭ クライアントの参加者の数が、先にいた人の画面でも、あとから入った人の画面でも、サーバーにいる人数と一致する
